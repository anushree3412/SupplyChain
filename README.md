# Sample Hardhat 3 Beta Project (minimal)

This project uses Hardhat only for Solidity compilation and ABI/artifact generation. Contract deployment is performed manually from Remix IDE using MetaMask on a public network such as Sepolia.

## What's included?

- `contracts/SupplyChain.sol` — Solidity contract.
- `frontend/` — React + Vite frontend.
- `artifacts/` — Hardhat-generated ABI and bytecode.
- `hardhat.config.ts` — compile configuration.

## Recommended workflow

1. Install root dependencies:

```bash
npm install
```

2. Install frontend dependencies:

```bash
cd frontend
npm install
```

3. Compile the contract with Hardhat to generate artifacts/ABI:

```bash
cd ..
npx hardhat compile
```

4. Deploy the contract from Remix IDE using `Injected Provider - MetaMask` on Sepolia.
   - Use the same `contracts/SupplyChain.sol` source or paste the ABI from `artifacts/contracts/SupplyChain.sol/SupplyChain.json`.
   - After deploying, copy the deployed contract address.

5. Configure the frontend with the deployed address:

```bash
cd frontend
cp .env.example .env
# Edit .env and set VITE_CONTRACT_ADDRESS to the Remix-deployed contract address
```

6. Start the frontend:

```bash
npm run dev
```

## Notes

- The React app reads the contract address from `frontend/.env`.
- The frontend still uses ABI generated by Hardhat compile, but does not deploy via Hardhat.
- The `scripts/deploy.js` file is no longer used for deployment.
